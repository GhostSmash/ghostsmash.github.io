# Smashh — link-in-bio

Static page (HTML + CSS + vanilla JS). No build tools, no framework.
Open `index.html` by double-click (works from `file://`) or upload the folder to GitHub Pages.

```
index.html      content: nick, tags, links, icons
styles.css      look (all colors come from CSS variables)
config.js       settings: view counter, Discord, wallpaper position/blur
script.js       theme from wallpaper, counter, player, Discord button
build.py        run after changing music or wallpaper (build.bat on Windows)
assets/
  avatar.jpg        your photo (square, 512x512+)
  wallpaper.jpg     background (.jpg / .png / .webp); colors follow it
  music/            put your audio files here
  site-data.js      generated by build.py, do not edit
```

## Music
1. Drop `.mp3 / .m4a / .ogg / .wav / .flac / .opus` files into `assets/music/`.
2. Run `build.py` (double-click `build.bat`, or `python build.py`).

Title = file name without extension. Length = read by the browser from the file.
One file = single-track player; several files = prev/next buttons appear.

## Wallpaper / adaptive theme
Replace `assets/wallpaper.*`, then run `build.py`. Accent colors, glow, card tint and
background darkening are derived from the picture. Huge images are shrunk automatically
into `wallpaper.optimized.jpg` (needs `pip install pillow`; your original is kept).

Why `build.py` is needed: browsers refuse to read pixels of local files opened from disk, so
the colors are measured once and stored in `assets/site-data.js`. On a real web host
(GitHub Pages etc.) the page measures the wallpaper itself.

## View counter
Shared counter through the free key-less Abacus API (see `config.js`).
A browser adds at most one view per 24 h. Opening the page from your own disk only reads the
number. If the service is unreachable, the last known number (or an em dash) is shown.

## Discord button
Discord cannot link to a profile by username, only by numeric user ID, so `config.js` holds
your ID and the button opens `discord.com/users/<ID>`.
Set `discord.userId` to `""` and the button copies your username to the clipboard instead.

## Icons
Telegram / GitHub / Discord are the original glyphs from the Simple Icons set, inlined as SVG
with `currentColor`, so they follow the accent color. To force another color:
`.social { color: #fff; }` in `styles.css`. 4PDA has no glyph in that set, so it is a text wordmark.
