Drop your audio files here (.mp3, .m4a, .ogg, .wav, .flac, .opus).

Then run build.py (double-click build.bat on Windows, or `python build.py`).
  - Track title  = the file name without the extension ("Artist - Song.mp3" -> "Artist - Song").
  - Track length = read by the browser from the audio file itself.
  - Order        = alphabetical, with numbers sorted naturally (2 before 10).
One file = a single-track player. Several files = the player gets prev/next buttons.
